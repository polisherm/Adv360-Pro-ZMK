Adv360 キー配列（2026-11-17）

矢印を右手の一番下の段に戻し、Fn の 4 行目に記号を戻した時点。キーの中の文字は、JIS 配列の Windows で実際に出る文字。小さい文字は Shift を押したときに出る文字か、長押しの役目。

Base（ふだんの層）

11/17 に動かしたキー 修飾キー・レイヤーの入口 一段高い列

Fn（親指の Delete か BackSpace を長押し）

点線のキーは何も出さない。何も書いていないキーは Base と同じ文字が出る。

COMMAND（無変換か変換を長押し）

左右とも、指ごとに同じコマンド。redo は Ctrl+Y を送る。ほかのキーは何も出さない。
