<typing_ergonomics_rules>

キーマップの配置を考えるときの、利用者の手と打ち方に関する事実。

<row_ease>
打ちやすい順に、ホーム段 ＞ 4 行目 ＞ 5 行目 ＞ 2 行目 ＞ 1 行目。
</row_ease>

<raised_column>
Mod・KEYPAD のキーがある内側の列（左右とも）は、ほかの列と高さが違う。
単押しなら押しにくくない。
文章の流れで打つと位置を探してしまうため、文字は置かない。
</raised_column>

<thumb_keys>
打ちやすいのは、Space・Delete・Enter・BackSpace の 4 か所（左右対称の位置）。
ほかの親指キーは少し打ちづらい。

Shift は Space と Enter の長押しにある。
普段は左（Space の長押し）を使い、右（Enter の長押し）はあまり使わない。
左だけで打ちづらいときに右を使うため、左右対称に置く。

無変換・変換のタップは IME のオン / オフに使う。
右 Alt の単押しは、Typeless などのアプリで使う。
</thumb_keys>

<hold_tap_misfire>
タップと長押しを兼ねるキーでレイヤーを頻繁に切り替えると、誤爆しやすい。
素早く打つと、親指を離す前に次のキーを押してしまうため。
押していた時間だけで判定する `tap-preferred` では、次のキーがレイヤー側の文字に化ける。
Fn と COMMAND の入口は、この理由で `balanced` にしている。
</hold_tap_misfire>

<left_hand_consonants>
左手は、どの指の列にもホーム段に母音がある（A・O・E・U と I）。
左手に子音を置くと、ローマ字では母音と同じ指の連続になる。
上段へ斜めに伸ばす連続（vi・fu）はきつい。人差し指以外の指でも同じと考える。
下段との往復（ku・ki）は、まだましに打てる。
</left_hand_consonants>

<individual_habits>
- q は SKK のカタカナ化に使う。SKK 側の設定は変えられる。
- Ctrl+A・C・V は手に馴染んでいるが、変えてもよい。今は COMMAND レイヤーにまとめている。
- 矢印は、文章を打つ途中でも頻繁に押す。
- `<` `>` は、親指の Shift ＋ `,` `.` で打つ。
- KEYPAD レイヤーは使っていない。
</individual_habits>

<ongoing_trial>
- 2026-11-08 から、F と V を 5 行目（人差し指・薬指）に置き、矢印を Fn レイヤーの同じ位置へ移して試している。
- 5 行目が打ちやすければ、空いている中指に K、小指に J を入れる。
- 矢印が Fn レイヤーにあるのが耐えられなければ、矢印を戻す。
- 空いている席（左人差し指の上段の 2 つ、右の一段高い列のホーム段）の使い道は決めていない。
</ongoing_trial>

</typing_ergonomics_rules>
