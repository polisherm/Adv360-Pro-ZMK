<layout_diagram_rules>

キー配列を図にするときは、`assets/layout-diagram.html` を土台にし、`layers` の中身を今のキーマップに合わせて書き換えて Artifact で公開する。

- キーの中には、JIS 配列の Windows で実際に出る文字を書く。ZMK の keycode 名は書かない
- 親指クラスターは、縦長の 2 キー（左は Delete と Space、右は Enter と BackSpace）と、内側の縦 2 段（左は Home と無変換、右は End と変換）でできている
- 親指の上段の 2 キーは、内側寄りの 2 列の上にある。左は Space の上に Ctrl、Home の上に Alt。右は End の上に Win、Enter の上に右 Alt
- 一段高い列は、灰色の帯で示す
