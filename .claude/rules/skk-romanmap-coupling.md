<skk_romanmap_coupling_rules>

利用者は CorvusSKK のかな変換表を独自に拡張している。
省略打ちの 2 打目は、文字ではなく物理キーの位置で決めている。
そのため、キーマップでキーを動かすと省略打ちが効かなくなる。

<before_moving_keys>
Base レイヤーでキーを動かす・消すときは、反映する前に変換表を確かめる。

- 変換表の正本は `C:/Users/polis/dev/my-tools/keyboard-layout-optimizer/data/romanmap.txt`。1 行に `ローマ字<TAB>ひらがな<TAB>カタカナ<TAB>半角カタカナ<TAB>フラグ`。
- 動かすキーが出す文字を 2 打目以降に含む行を洗い出す。
- 洗い出した行の役目を、動かした後も同じ物理位置から打てるようにする。キーマップ側でその位置に同じ文字を残すか、変換表の 2 打目を書き換えて利用者に取り込んでもらう。
- 変換表を書き換える手順は、Vault の `50_Knowledge/個人/入力環境/CorvusSKKの設定項目メモ.md` にある。
</before_moving_keys>

<current_second_keys>
今の省略打ちの 2 打目と、その物理位置。

| 2 打目 | 意味 | 物理位置 |
|---|---|---|
| `v` | Xうう（ku → くう） | 左人差し指の上段 |
| `f` | Xうい | 左人差し指の上段の内側 |
| `k` | Xうん | 左人差し指の下段 |
| `x` | Xいん | 左人差し指の下段の内側 |
| `j` | Xえん | 左中指の下段 |
| `q` | Xおん | 左薬指の下段 |
| `c` | Xえん | 右中指の上段 |
| `'` `,` `.` `;` `\` | Xあい・Xおう・Xえい・Xあん・Xあい | 記号キーの位置 |

左人差し指の上段の `v` と `f` は、省略打ちのためだけに置いている。文字として打つ `v` と `f` は右手の一番下の段にあり、同じ文字が 2 か所から出る。
</current_second_keys>

<other_skk_keys>
変換表のほかに、CorvusSKK の設定もキーの位置に依存している。

- 候補の選択キーは `a` `o` `e` `u` `i` `d` `h` `t` `n`（左右のホーム段）。
- `q` はかなモードの切り替え、`l` は略語変換、`L` は全角英字。
- 候補リストの移動に矢印・Home・End を使う。
</other_skk_keys>
